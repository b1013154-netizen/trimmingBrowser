# TrimmingBrowser 使い方説明書

TrimmingBrowser は、ブラウザ（や他のアプリ）の画面のうち **見たい部分だけを好きな形で切り出して、その部分と同じ大きさの枠のない小窓で表示する** Windows 用の無料ツールです。
タブ・アドレスバー・タイトルバー・おすすめ欄などは、切り出した範囲に含めない限り表示されません。小窓は **ドラッグで自由に拡大・縮小でき、中身も同じ比率で大きさが変わります**。切り出した部分は、元のページと同じように **クリック・再生・一時停止・スクロールなどの操作ができます**。

> 例: YouTube の動画部分だけを切り出して画面の隅に置き、作業しながら見る。どのサイトでも同じように使えます。

## 1. はじめに

### 起動とタスクトレイ

- 起動するとホーム画面が開き、画面右下のタスクトレイにアイコンが表示されます。
- ホーム画面を閉じてもアプリは終了しません。もう一度開くときはタスクトレイのアイコンをクリックします。
- 終了するときは、タスクトレイのアイコンを右クリック →「終了」を選びます。終了すると、切り出していた窓はすべて元の状態に戻ります。

### 初回起動時の警告

「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押してください（コード署名をしていないために表示されます）。

## 2. ページを開いて切り出す

ホーム画面の「開いて切り出す」で操作します。

1. **開くページ** に URL を入力します（例: `https://www.youtube.com/`）。`youtube.com` のように `https://` を省いても開けます。
2. **開き方** を選びます（次の表を参照）。
3. **切り出す図形** と **開くウィンドウの大きさ** を選び、「開く」を押します。
4. ページが枠の少ない窓で開き、窓の上に「✂ 範囲を選ぶ」が表示されます。動画を再生する、ログインするなど、見たい部分が映る状態にしてから「✂ 範囲を選ぶ」を押します。
5. 画面が暗くなったら、見たい部分をドラッグで囲み、「✂ 切り出す」（または Enter）を押します。
6. 囲んだ部分と同じ大きさの小窓に切り替わります。元の窓は小窓の中に入るので、画面には小窓だけが残ります。

### 開き方の違い

| 開き方 | 向いている使い方 | 注意点 |
|---|---|---|
| **いつものブラウザ（ログインしたまま）** | ログインが必要なサイト、YouTube Premium、いつもの拡張機能（広告ブロックなど）を使いたいとき | Chrome または Edge が必要です。タブとアドレスバーのない窓（アプリモード）で開きます |
| **内蔵ブラウザ（ログインなし）** | ログインが不要なページを、いつものブラウザと分けて見たいとき | いつものブラウザとは履歴・ログインを共有しません。Google アカウントはログインできない場合があります |

内蔵ブラウザでは、Alt + ← で戻る、Alt + → で進む、F5 で再読み込みができます。

### 大きさの変え方

切り出した小窓は、あとから自由に大きさを変えられます（縦横の比率は保たれます）。

- 操作バーの **−／＋** で 1 段階ずつ小さく・大きくします。
- 操作バーの **⇔** を左右にドラッグすると、好きな大きさにできます。
- 内蔵ブラウザで開いた小窓は、窓の端をドラッグしても大きさを変えられます。

内蔵ブラウザでは、ページ全体を拡大・縮小するので、切り出した部分がそのまま大きく・小さくなります。いつものブラウザと開いている窓では、元の窓ごと同じ比率で大きさを変えます。動画のように窓に合わせて大きさが変わる部分はそのまま拡大・縮小されますが、ページによっては文字の折り返しなどが変わり、範囲が少しずれることがあります。そのときは ✂ で選び直してください。

## 3. 範囲の選び方と図形

範囲を選ぶ画面の上にある図形ボタンで、切り出す形を選びます。

| 図形 | 選び方 |
|---|---|
| 四角形 | ドラッグで囲みます。Shift を押しながらで正方形 |
| 角丸 | 角の丸い四角形。ドラッグで囲みます |
| 楕円 | ドラッグで囲みます。Shift を押しながらで正円 |
| 六角形 | ドラッグで囲んだ範囲に収まる六角形 |
| ひし形 | ドラッグで囲んだ範囲に収まるひし形 |
| 自由な多角形 | 角を順にクリックして囲みます。最初の点のクリック、ダブルクリック、Enter のいずれかで閉じます。Backspace で 1 つ前の点に戻ります |

- 囲んだあとは、範囲の中をドラッグで移動、四隅の丸いつまみで大きさの変更ができます（自由な多角形は各頂点をドラッグで調整）。
- 「やり直す」で囲み直し、「キャンセル」（または Esc）で選ぶのをやめます。
- 範囲は窓の中だけで選べます。タイトルバーなどの枠は、範囲に含めない限り表示されません。

## 4. 切り出した窓の操作バー

切り出した窓にマウスを乗せると、窓の上に操作バーが表示されます（マウスを離すと消えます）。

| ボタン | はたらき |
|---|---|
| ⠿（つまみ） | ドラッグで窓を移動します |
| − ／ ＋ | 小窓を小さく・大きくします |
| ⇔ | 左右にドラッグして、小窓の大きさを自由に変えます |
| ✂ | 範囲や図形を選び直します |
| 📌 | 常に最前面に表示する／しないを切り替えます（初期値: 最前面） |
| ◐ スライダー | 不透明度（20〜100%）を変えます。透かして後ろの画面を見られます |
| 🖱 | クリック透過。オンにすると窓をクリックしても後ろの画面が操作されます |
| ★ | お気に入りに保存します（5 章） |
| ⤺ | 切り出しをやめて、元の窓に戻します（窓は閉じません） |
| ⋯ | ホーム画面や説明書を開きます |
| ✕ | 窓を閉じます |

> クリック透過中は窓をクリックできません。戻すときは操作バーの 🖱 を押すか、ショートカットキー（初期値 Ctrl + Alt + C）を押してください。

## 5. お気に入り

操作バーの ★ を押すと、次の内容をまとめて保存します。

- 開いているページの URL と開き方（いつものブラウザ／内蔵ブラウザ）
- 元の窓の大きさ、切り出した範囲と図形
- 小窓の大きさと画面上の位置
- 不透明度、最前面の設定

ホーム画面の「お気に入り」で「開く」を押すと、同じページを開き、同じ範囲を同じ大きさ・同じ位置の小窓で自動的に切り出します。タスクトレイのアイコンを右クリック →「お気に入り」からも開けます。

- 名前は ✎ で変えられます（初期値はページのタイトル）。↑↓ で並べ替え、🗑 で削除します。
- いつものブラウザで開くときは、ページの表示を待ってから切り出します。表示が遅いページで範囲がずれる場合は、設定の「お気に入りの待ち時間」を長くしてください。
- ページの作りが変わると、保存した範囲が見たい部分からずれることがあります。そのときは ✂ で選び直してから、もう一度 ★ で保存してください。
- 「開いている窓から」切り出した窓は URL がわからないため、お気に入りには保存できません。

## 6. 開いている窓から切り出す

ホーム画面の「開いている窓から」に、いま開いているウィンドウの一覧が表示されます。「✂ 切り出す」を押すと、そのウィンドウの範囲を選ぶ画面になります。ブラウザ以外（動画プレーヤー、資料、他のアプリ）も切り出せます。

切り出したいウィンドウを前面にして **Ctrl + Alt + X**（初期値）を押しても、同じように切り出せます。

## 7. 設定

| 項目 | 内容 |
|---|---|
| 使うブラウザ | 「いつものブラウザ」で使うブラウザ。自動（Chrome → Edge の順に探す）／Chrome／Edge／場所を指定 |
| 最初に選ぶ開き方 | ホーム画面を開いたときに選ばれている開き方 |
| 最初に選ぶ図形 | ホーム画面を開いたときに選ばれている図形 |
| 不透明度・常に最前面 | 新しく切り出した窓の初期値 |
| 操作バー | オンにするとマウスを乗せたときだけ表示、オフにすると常に表示 |
| お気に入りの待ち時間 | お気に入りを開いたとき、切り出すまで待つ時間 |
| ショートカットキー | 前面の窓を切り出す（初期値 Ctrl+Alt+X）、クリック透過の切り替え（初期値 Ctrl+Alt+C） |

設定とお気に入りは `%APPDATA%\TrimmingBrowser\config.json` に保存されます。

## 8. 困ったときは

| 症状 | 対処 |
|---|---|
| 「Chrome または Edge が見つかりません」と出る | 設定の「使うブラウザ」で「場所を指定」を選び、chrome.exe などを指定します |
| 切り出した窓が操作できない | クリック透過がオンになっていないか確認します（🖱 または Ctrl + Alt + C） |
| 窓がどこにあるかわからない | タスクトレイのアイコンを右クリック →「切り出しをすべて元に戻す」で元の窓に戻ります。小窓はタスクバーにも表示されます |
| 小窓を閉じたらブラウザの窓も閉じた | 小窓を閉じると、中に入っている窓も閉じます（開いている窓から切り出した場合は閉じずに元に戻ります）。窓を残したいときは ⤺ で元に戻してください |
| 内蔵ブラウザで Google にログインできない | Google は組み込みブラウザからのログインを制限しています。「いつものブラウザ」で開いてください |
| お気に入りを開くと範囲がずれる | 設定の「お気に入りの待ち時間」を長くするか、範囲を選び直して保存し直します |
| ショートカットキーが効かない | 他のアプリが同じキーを使っている可能性があります。設定画面に表示されるメッセージを確認し、別の組み合わせにします |

> アプリが強制終了した場合など、ブラウザの窓が小窓の中に入ったまま見えなくなったときは、そのブラウザを一度終了して開き直してください。
