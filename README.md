# TrimmingBrowser

ブラウザ（や他のアプリ）の画面のうち、**見たい部分だけを好きな形で切り出して、枠のない小さな窓で表示する** Windows 用の無料ツールです。
タブ・アドレスバー・タイトルバーなどは、切り出した範囲に含めない限り表示されません。切り出した部分はそのままクリック・再生・スクロールなどの操作ができます。

例: YouTube の動画部分だけを切り出して画面の隅に置き、作業しながら見る（サイトには依存しません）。

## 主な機能

| 分類 | 内容 |
|---|---|
| 開き方 | **いつものブラウザ**（Chrome / Edge のアプリモード。ログイン状態・拡張機能をそのまま使える）／**内蔵ブラウザ**（ログインなし・履歴を分ける）／**開いている窓**（どのアプリでも） |
| 切り出す図形 | 四角形・角丸・楕円（正円）・六角形・ひし形・自由な多角形 |
| 範囲の調整 | ドラッグで囲む、中をドラッグで移動、四隅で大きさ変更、Shift で正方形・正円 |
| 操作バー | マウスを乗せたときだけ表示。移動・選び直し・常に最前面・不透明度・クリック透過・お気に入り保存・元に戻す・閉じる |
| お気に入り | URL・開き方・窓の大きさ・範囲・図形・位置・不透明度をまとめて保存し、ワンクリックで同じ表示を再現 |
| ショートカット | 前面の窓を切り出す（Ctrl+Alt+X）、クリック透過の切り替え（Ctrl+Alt+C） |
| 説明書 | [使い方説明書](docs/使い方説明書.md) を同梱。ホーム画面の「ヘルプ（説明書）」から読めます |

## しくみ

切り出しは、対象のウィンドウそのものに Windows の「ウィンドウ領域」（`SetWindowRgn`）を設定して、選んだ図形の外側を表示しないようにしています。
画像を写しているのではなく本物のウィンドウなので、切り出した部分はそのまま操作でき、動画の音も普段どおり出ます。
アプリを終了すると、切り出していたウィンドウはすべて元に戻ります。

## インストール

GitHub の Actions タブ →「Windows build」の最新の実行結果 → Artifacts の `TrimmingBrowser-Windows` をダウンロードして展開します。

- `TrimmingBrowser-Setup-x.y.z.exe`: インストーラー（スタートメニューとデスクトップにショートカットを作成）
- `TrimmingBrowser-Portable-x.y.z.exe`: インストール不要版

初回起動時に「Windows によって PC が保護されました」と出た場合は、「詳細情報」→「実行」を押してください（コード署名をしていないために表示されます）。

## 開発者向け

```bash
npm install
npm start          # 開発用に起動
npm run check      # 構文チェックと、図形・設定のテスト
npm run smoke      # Windows 上で実際に窓を開いて切り抜きを確かめる（CI でも実行）
npm run dist       # Windows 上でインストーラーとポータブル版を作成（dist/）
```

| ファイル | 役割 |
|---|---|
| `src/main.js` | ホーム画面・タスクトレイ・ホットキー・ページを開く処理・お気に入り |
| `src/trim.js` | 切り出し中の窓の管理（範囲選択、切り抜きの維持、操作バー、移動、元に戻す） |
| `src/win32.js` | Windows API（ウィンドウ領域・最前面・不透明度・クリック透過・ウィンドウ一覧）を [koffi](https://koffi.dev/) で呼び出す |
| `src/browser.js` | Chrome / Edge を探してアプリモードで開き、新しいウィンドウを見つける |
| `src/shapes.js` | 図形の座標計算（メインプロセスと画面の両方で使う） |
| `src/config.js` | 設定の既定値・検証・保存 |
| `src/renderer/` | ホーム画面・範囲選択画面・操作バー（HTML / CSS / JS、フレームワーク不使用） |

設定とお気に入りは `%APPDATA%\TrimmingBrowser\config.json` に保存されます。
